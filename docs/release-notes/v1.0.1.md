## Changes since v1.0.0

- **Removed a non-public model reference** from `NOTICE`, `manifest.json` and the build scripts. The release checks now use a local, git-ignored deny list, so excluded material is never named in the repository or the release assets.
- **Added the public eBFE San Marcos 1D model Stream248**, computed by CLB in HEC-RAS 7.0.1. All three files are in `smoke` and `core`:
  - `ebfe/Stream248.g01`: 1D geometry with cross-section property tables;
  - `ebfe/Stream248.p01`: the delivered steady plan, computed unchanged;
  - `clb/Stream248.p02`: a CLB-added unsteady plan on the eBFE geometry.

  Source: https://ebfedata.s3.amazonaws.com/12100203_SanMarcos/12100203_Models.zip, `Hydraulic_Models/1210020304/Stream248/`. Receipts are in `provenance/ras701-corpus/`.
