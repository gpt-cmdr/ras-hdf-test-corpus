**Support policy:** CI tests HEC-RAS 7.0.1. Older versions are best effort, and unsupported layouts must be refusals, never wrong data.

## Contents

- **HEC-RAS 7.0.1 fixtures** in `smoke`/`core`:
  - HEC example plans and geometries run in 7.0.1, including SI 2D with and without sediment, 1D sediment, bridges, culverts, inline/lateral structures, storage areas, SA/2D connections, breaches, junctions, encroachments, pumps and pipe networks;
  - reference lines and points;
  - 7.0.1 RAS Mapper land cover, soils, SCS/Green-Ampt/deficit-constant infiltration, terrain with GeoTIFF, and a stored map;
  - a 7.0.1-written eBFE geometry with refinement regions;
  - synthetic Albers-CRS and `Infiltration Parameters` fixtures.
- **Native property tables:** every property-table family has a native 7.0.1 file in `core`.
- **Known issue (`ebfe701/1101001404.g01.rr`):** HEC-RAS 7.0.1 rejected the 6.3.1 mesh (cells with more than 8 sides), so the file has no faces or property tables. Not fixed, because the fixture is only used to read refinement regions and other geometry features. Its test groups are `detection`, `metadata` and `geometry_features`.

## Expected values

`expected.tar.gz` holds `expected/<fixture-id>/oracle.json` for 136 HDF fixtures: 1,065 cases, 1,049 results and 16 recorded refusals. `expected/INDEX.json` lists each oracle's hash. `expected-parquet.tar.gz` (optional, for debugging) holds full tabular values.

**Generator environment** (Python 3.12.11, Windows; `scripts/requirements-oracle-generator.lock.txt`):
- ras-commander 0.108.1, ras-commander-fast-hdf (engine) 0.2.1;
- h5py 3.16.0, numpy 2.5.4, pandas 3.1.0;
- xarray 2026.9.0, geopandas 1.2.0, shapely 2.2.0, pyproj 3.8.0, pyarrow 26.0.0.

Excerpts were built and verified with h5py 3.15.1 / HDF5 1.14.6.
